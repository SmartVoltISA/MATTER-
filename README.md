# MATTER-

## RU
Исследование материи, её состояний, структуры, взаимодействий и переходов. Отдельно проверяются состав, свойства, организация и изменение состояния. Гипотеза ≠ факт; расчёт ≠ эксперимент.

## EN
Research of matter, its states, structure, interactions and transitions. Composition, properties, organization and state changes are tested separately. Hypothesis ≠ fact; calculation ≠ experiment.

## 中文
研究物质及其状态、结构、相互作用与转变。分别研究组成、性质、组织方式和状态变化。假设≠事实；计算≠实验。

## Foundation
SYSTEM-FOUNDATION → MATTER- → hypothesis → experiment → result → verification
